# Skills

Each subdirectory here is one agentic coding skill — a `SKILL.md` plus whatever `assets/`, `references/`, or `evals/` it needs — following the same structure as [ragTechDev/lean-canvas-model](https://github.com/ragTechDev/lean-canvas-model)'s `.agents/skills/`.

See the root `README.md` for how to install and use a skill from this repo.
